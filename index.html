Chaos Theory

ChaosTrace

Toolkit Python léger pour la détection de transitions de régime, d'événements « foil drop » et d'anomalies cachées dans des séries temporelles multivariées haute fréquence. Reconstruction d'espace de phase, analyse RQA et métriques inspirées du chaos (Takens, proxy de Lyapunov).

Phase SpaceRQALyapunov Matrix ProfileDeep LearningCausal
⚡ Exemple d'utilisation
# Mode hybride : chaos + Matrix Profile + causal
python -m chaostrace.cli.run_hybrid \
    --input telemetry.csv \
    --out results/ \
    --enable-mp --enable-causal \
    --mp-col boat_speed
→ anomalies_hybrid.csv · metrics_hybrid.json · fig_timeline_hybrid.png

Active Learning

AstroOracle

Oracle à apprentissage actif pour le triage d'anomalies astronomiques. Récupère des cutouts SkyView, classe les candidats via score d'anomalie, acquisition et diversité. Interface CLI et web pour l'annotation, avec ré-entraînement automatique.

Active LearningSkyViewPlotly 3D FastAPIGaiaExplainability
⚡ Exemple d'utilisation
# Serveur web avec dashboard interactif
astrooracle serve \
    --candidates candidates.parquet \
    --annotations annotations.csv

# → http://127.0.0.1:8000/
→ Landing Plotly 3D · Dashboard annotations · Graph anomaly · LIME

Graph Analysis

AstroGraphAnomaly

Détecte des sources astronomiques inhabituelles dans les données Gaia. Combine le scoring d'anomalies par features avec une analyse de graphe k-plus-proches-voisins sur la sphère céleste. Explainability LIME, génération de prompts LLM et rapport HTML autonome.

k-NN GraphIsolation ForestLOF LIMELLM PromptsGraphML
⚡ Exemple d'utilisation
# Workflow complet sur données Gaia
python run_workflow.py \
    --mode gaia \
    --ra 266.4051 --dec -28.936175 \
    --radius-deg 0.5 --limit 2000 \
    --out results/ \
    --plots --explain-top 10
→ scored.csv · graph_topk.graphml · report.html · plots/*.png · llm_prompts.jsonl
